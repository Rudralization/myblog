    • In CSS, a Class is used to apply the same style to many HTML elements. You write it in HTML using the 'class' attribute, and in CSS you select it using a dot (.) selector. For example, '.box { color: red; }'. Classes are very useful because you can reuse them again and again on different elements. This helps keep your code simple and organized. Unlike an id, a class is not limited to one element, so it is more flexible for styling.
